# 体重・体脂肪率

- 状態: 実装済み

> 見た目と配置は [見た目の刷新](redesign.md) で変更した（入力欄を横に並べる、グラフを2つのカードに分ける）。操作はこの仕様のまま。

## 目的

体重と体脂肪率を毎日記録し、増えているか減っているかの傾向をつかめるようにする。

- 記録と見返しに絞る。目標の管理（目標体重、あと何 kg か）は今回は作らない
- 最初に作る記録として、ログイン・DB・公開までの流れを通しで確かめる役割もある（[decisions/0004](../decisions/0004-first-feature-weight.md)）

## 記録する項目

| 項目 | 型 | 必須 | 例 | 備考 |
|---|---|---|---|---|
| 日付 | 日付 | 必須 | 2026-11-18 | 最初から今日の日付が入っている。**1日1件**。過去の日付は入力できる。未来の日付はできない |
| 体重 | 数値（kg） | 必須 | 65.3 | 小数点以下1桁。20〜300 |
| 体脂肪率 | 数値（%） | 任意 | 18.5 | 小数点以下1桁。1〜75。体組成計がない日も記録できるように任意にする |

- 記録はユーザーごとに分かれる。ほかの人の記録は見えない・変えられない
- **同じ日付の記録がすでにあるときに保存すると、その日の記録を上書きする**（2件目は作らない）
- 「今日」と「未来の日付」は **日本時間** で判定する

## 画面と操作

- **置き場所**: 専用のページ `/weight` に、入力・グラフ・一覧をまとめる。トップ（`/`）は後のダッシュボード用に空けておく。`/weight` へは、ナビゲーション（[layout.md](layout.md)）から移動する
- **入力**: 日付・体重・体脂肪率を入れて保存する
- **一覧**: 記録を日付の新しい順に、30件まで並べる。各行に日付・体重・体脂肪率を表示する
- **グラフ・集計**: 直近30日の体重と体脂肪率の推移を折れ線グラフで表示する
- **編集・削除**: 一覧の記録を選んで、体重・体脂肪率を直す、または削除する。削除の前に「削除しますか？」と確認を出す

## 入力の手軽さ

- 日付には最初から今日の日付を入れておく
- 体重・体脂肪率の欄には、前回の記録の値を最初から入れておく（少し変えるだけで保存できる）
- スマホでは、数字と小数点を打てるキーボードを出す

## 受け入れ条件

この条件を満たせば完成とする。

- [x] ナビゲーション（スマホは下のバー、PC はサイドバー）の「体重・体脂肪率」から `/weight` を開ける
- [x] `/weight` を開くと、日付に今日の日付（日本時間）が入っている
- [x] 体重だけを入力して保存できる（体脂肪率は空でよい）
- [x] 体重と体脂肪率を入力して保存すると、一覧の先頭に表示される
- [x] 体重が空のまま保存しようとすると、エラーが表示され、保存されない
- [x] 範囲外の値（体重 20 kg 未満・300 kg より大きい、体脂肪率 1 % 未満・75 % より大きい）や未来の日付では、エラーが表示され、保存されない
- [x] 過去の日付を選んで保存できる
- [x] すでに記録がある日付で保存すると、その日の記録が上書きされ、一覧の件数は増えない
- [x] 2回目以降に `/weight` を開くと、体重・体脂肪率の欄に前回の値が入っている
- [x] 一覧の記録の体重を直して保存すると、一覧とグラフに反映される
- [x] 一覧の記録の削除を選ぶと確認が出て、確定すると一覧とグラフから消える。取り消すと消えない
- [x] グラフに、直近30日の体重と体脂肪率の推移が表示される
- [x] 一覧には新しいものから30件までが表示される
- [x] 別のアカウントでログインすると、自分の記録だけが表示される
- [x] スマホの幅で、入力・一覧・グラフが崩れずに使える
