# カレンダー

- 状態: 実装済み

## 目的

体重・体脂肪率と筋トレの記録を、日付で並べて見られるようにする。

- どの日に体重を測ったか、どの日に筋トレをしたかが、1か月分ひと目でわかる
- 日付を選ぶと、その日の記録の内容を見られる
- 記録どうしの関係（例: 筋トレの頻度と体重の変化）に気づくきっかけにする（[product.md](../product.md) の目的）

## 記録する項目

なし（体重・体脂肪率と筋トレの記録を読むだけで、新しく保存するデータはない）。

- 表示するのはログイン中のユーザーの記録だけ

## 画面と操作

- **置き場所**: 専用のページ `/calendar`。ナビゲーション（スマホは下のバー、PC はサイドバー）に「カレンダー」（カレンダーのアイコン）を足す
- **カレンダー**: 1か月分のマス目を表示する。週は日曜日から始める
  - 開いたときは今月（日本時間）を表示し、今日を選んでおく
  - 「前の月」「次の月」で移動する。未来の月にも移動できる
  - 選んだ日を URL に残す（例: `/calendar?date=2026-11-18`）。再読み込みしても同じ日が開き、ブラウザの「戻る」で前に見ていた日に戻れる
  - 記録がある日には、小さな印を出す。体重・体脂肪率と筋トレで、印の色（またはアイコン）を分ける
  - 今日のマスは、ほかの日と見分けられるようにする
- **選んだ日の記録**: カレンダーの下（PC の幅が 1024px 以上のときは右）に表示する
  - 体重・体脂肪率：その日の値（例: 65.3 kg / 18.5 %）
  - 筋トレ：その日の種目と、種目ごとのセット（例: ベンチプレス 60kg × 10回）
  - 記録がない日は「記録がありません」
  - 体重・体脂肪率のページ（`/weight`）と筋トレのページ（`/workout`）へのリンクを置く
- **編集・削除**: カレンダーではしない（見るだけ）。それぞれのページで行う

## 入力の手軽さ

- 入力はしない。開いてすぐ今日の記録が見え、1タップで日付を切り替えられるようにする
