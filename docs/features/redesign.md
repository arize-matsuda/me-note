# 見た目の刷新

- 状態: 実装済み

## 目的

アプリ全体の見た目を整え、毎日開きたくなる、落ち着いた画面にする。

- デザインは「案C ラベンダー」（人が参考画像をもとに選んだもの）に合わせる。デザイン案: https://claude.ai/artifact/DkxPoFFEixyXUGgPSwwgRp
- **見た目だけを変える**。今あるデータと機能だけを使い、新しい機能は足さない

## 記録する項目

なし（見た目だけの変更で、新しく保存するデータはない）。

## 画面と操作

### 全体の見た目

| | 内容 |
|---|---|
| 背景 | 薄いラベンダーがかったグレー（例: `#F5F5FA`） |
| カード | 白。うすい枠線、やわらかい影、角の丸み 16px 前後 |
| メインの色 | 紫（例: `#5B5BD6`）。ボタン、今いるページ、体重・体脂肪率のグラフ、入力中の枠に使う |
| 筋トレの色 | オレンジ（例: `#F2A33A`）。グラフの「筋トレをした日」の印、カレンダーの筋トレの印、筋トレのカードのアイコンに使う |
| 文字 | 濃い紺に近い黒。補足の文字はグレー（白い背景で読みやすい濃さにする） |
| フォント | Noto Sans JP（`next/font/google` で読み込む。ライブラリは追加しない） |
| 数字 | 桁をそろえる（`tabular-nums`） |

- 色は `web/src/app/globals.css` のテーマの変数（`--primary` など）で決め、各画面はその変数を使う。画面ごとに色の値を直接書かない
- 体重・体脂肪率の印の色は、これまでの水色から紫（メインの色）に変える。筋トレはオレンジのまま
- shadcn/ui の部品（`src/shared/components/ui/`）は直接書き換えない。見た目はテーマの変数と、使う側の `className` で変える
- 文字と背景の色の差は、読みやすさの目安（4.5:1 以上）を満たす
- ダークモードは今回は対応しない（今も使っていない）

### ナビゲーション

- **PC のサイドバー**
  - 一番上に、紫の四角のマークと「me-note」
  - 今いるページは、うすい紫の背景と紫の文字で目立たせる
  - 一番下に、ユーザー名（「○○さん」と頭文字の丸）と、ログアウトのボタン（アイコン）を並べる
- **スマホの下のバー**
  - 今いるページは、アイコンの後ろにうすい紫の丸い背景を付け、紫の文字にする
- 項目と並び順はこれまでどおり

### 本文の配置

- PC の本文の最大幅を 1152px に広げ、サイドバーの右の残りの幅の中で中央に置く
- 各ページの見出しは大きめ（スマホ 24px・PC 28px 前後）にする
- 2列にするなどの配置の切り替えは、これまでどおり幅 1024px 以上（`lg`）から。ホームの上の段だけ、幅 1280px 以上（`xl`）で1行にまとめる

### ホーム

1. **見出し**: 「ホーム」と「○○さん、おかえりなさい」。PC では右に今日の日付（例: 2026年11月19日（木））を表示する（日付は切り替えない）
2. **今日の記録**: 体重・体脂肪率と筋トレを1行ずつ。済んだものは紫の丸にチェック、まだのものは空の丸と「記録する」のリンク。右上に「1 / 2 済み」のように数を出す
3. **数字のカード（4つ）**: アイコン、名前、大きな数字、補足の1行
   - 体重: 最新の値。補足に 7日前より・30日前よりの増減（これまでと同じ計算）
   - 体脂肪率: 最新の値。補足に記録した日。記録がなければ「—」
   - 今週の筋トレ: 日数
   - 今月の筋トレ: 日数
4. **体重の推移（直近30日）**: これまでのグラフ（体重の線と筋トレをした日の印）を、新しい色にする
5. **今月の筋トレ**: 今月のカレンダー。筋トレをした日をオレンジの丸、今日を紫の輪で示す。「カレンダーへ」のリンクでカレンダーのページに移動する（このカレンダーでは日付を選べない、月も切り替えない）

- 配置
  - スマホ: 1 → 2 → 3（2列×2段）→ 4 → 5 の順に縦に並べる
  - 1024px 以上: 2 を横いっぱい、その下に 3 を4つ横に並べる。下の段に 4 と 5 を左右に並べる（4 を広く）
  - 1280px 以上: 2 と 3 を1行に並べる（2 を広く）
- スマホのログアウトボタンは、これまでどおりホームの一番下に置く

### 体重・体脂肪率

- **記録する**: 日付、体重と体脂肪率（横に2つ並べる）、保存ボタン。体重の入力欄は大きめの文字にする。「体脂肪率は空でも保存できます」と補足を出す
- **グラフ**: 体重と体脂肪率を別のカードに分け、それぞれに最新の値を大きく表示する。体重のカードには 7日前よりの増減も出す
- **最近の記録**: 日付・体重・体脂肪率・編集と削除のボタン（これまでどおりの操作）
- 配置: 1024px 以上では、左に「記録する」と「最近の記録」、右に2つのグラフを置く。スマホでは 記録する → グラフ → 最近の記録 の順

### 筋トレ・カレンダー・ログイン・新規登録

- 配置と操作はこれまでどおり。カード、ボタン、入力欄、色を新しい見た目にそろえる
- カレンダーの印: 体重・体脂肪率は紫、筋トレはオレンジ。選んだ日は紫の背景
- ログイン・新規登録: 背景の上に白いカードを置き、上に「me-note」のマークを出す

## 入力の手軽さ

- 押せる場所（ボタン・リンク・入力欄）は、高さ 44px 以上を目安にする
- 記録の操作の手数は変えない
