# プルダウンのデザイン変更

- 状態: 実装済み

## 目的

アプリの中のプルダウン（選択肢から1つ選ぶ部品）を、見た目の刷新（[redesign.md](redesign.md)）の「案C ラベンダー」にそろえる。

- 今のプルダウンはブラウザ標準の部品のため、閉じているときの見た目がほかの入力欄とそろっておらず、開いたときの一覧も OS やブラウザの見た目になる
- 閉じているときも開いたときも、アプリの見た目（白いカード、紫のメインの色、大きめで押しやすい行）にする
- **見た目と選び方だけを変える**。選べる項目、並び順、選んだあとの動きはこれまでどおり

この仕様は、人から「おすすめで決めてよい」と任されて AI が決めた。

## 記録する項目

なし（見た目だけの変更で、新しく保存するデータはない）。

## 画面と操作

### 対象のプルダウン

| 画面 | プルダウン | 選んだあとの動き（これまでどおり） |
|---|---|---|
| `/workout` の記録の欄 | 種目 | 前回の重量・回数が入る |
| `/workout` の記録の欄 | メニュー | メニューの種目が並ぶ。「使わない」でこれまでの入力に戻る |
| `/workout/menus` の作る・直す | 種目を選んで足す | 選んだ種目がメニューの最後に入り、プルダウンは「種目を選んで足す」に戻る |

### 閉じているとき

- 高さ 44px 以上。角の丸み・枠線・背景（白）・文字の大きさを、ほかの入力欄（メニュー名など）とそろえる
- 右に下向きの矢印を出す
- 何も選んでいないときは、薄い文字で「種目を選ぶ」などの案内を出す
- 押せないとき（足せる種目がないとき）は、薄く表示する
- 入力のエラーがあるときは、ほかの入力欄と同じく赤い枠にする

### 開いたとき

- プルダウンのすぐ下に、白いカードの一覧（角の丸み、やわらかい影）を出す。下に場所がなければ上に出す
- 一覧の幅は、プルダウンと同じ幅以上
- 1行の高さは 44px 以上
- 今選んでいる項目は、右にチェックの印を付ける
- 指やマウスを乗せた行・キーボードで選んでいる行は、うすい紫の背景にする
- 項目が多いときは、一覧の中でスクロールできる（画面からはみ出さない）
- 一覧の外を押す、または Esc キーで閉じる。閉じても選んでいた項目は変わらない

### 操作

- PC: クリックで開いて選ぶ。キーボード（Tab で移る、Enter・Space・↓で開く、↑↓で動く、Enter で決める）でも選べる
- スマホ: タップで開いて、タップで選ぶ（OS の選び方の画面は出さない）
- 画面の読み上げで、プルダウンの名前（「種目」など）と選んでいる項目がわかる

### 作り方の方針

- shadcn/ui の Select の部品を追加して使う（`pnpm dlx shadcn@latest add select`）。中身はすでに入っている Base UI を使い、新しいライブラリは入れない
- `src/shared/components/ui/` の中は書き換えず、色や大きさはテーマの変数と、使う側の `className` で決める

## 入力の手軽さ

- 押せる場所を大きく（44px 以上）し、スマホで選びやすくする
- 選ぶ手数は変えない（開く → 選ぶ の2タップ）
