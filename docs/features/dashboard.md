# ダッシュボード

- 状態: 確認済み

## 目的

アプリを開いてすぐに、今日の記録の状況と、体重・筋トレの最近の様子がわかるようにする。

- 今日まだ記録していないものに気づき、すぐ記録しに行ける
- 体重の増減と筋トレの頻度を並べて見て、記録どうしの関係（例: 筋トレの頻度と体重の変化）に気づくきっかけにする（[product.md](../product.md) の目的）

## 記録する項目

なし（体重・体脂肪率と筋トレの記録を読むだけで、新しく保存するデータはない）。

- 表示するのはログイン中のユーザーの記録だけ

## 画面と操作

- **置き場所**: ホーム（`/`）の今の内容を、ダッシュボードに置き換える。ナビゲーションの名前は「ホーム」のまま
- **見るだけ**: ダッシュボードでは記録しない。記録は各ページへのリンクから行う
- 一番上に、ログイン中のユーザー名を「○○さん」と小さく表示する
- 次の4つのカードを並べる
  1. **今日の記録**: 今日（日本時間）、体重・体脂肪率を記録したか、筋トレをしたか。まだのものには、そのページへのリンクを出す
  2. **体重・体脂肪率**: 最新の記録の値（日付つき）と、7日前・30日前と比べた体重の増減（例: 7日前より −0.4 kg）
     - 7日前・30日前は、最新の記録の日付から数える
     - ちょうどその日に記録がなければ、その日より前でいちばん近い記録と比べる。比べられる記録がなければ「比べる記録がありません」と表示する
     - 体重の記録が1件もなければ「まだ記録がありません」と表示し、記録のページへのリンクを出す
  3. **筋トレ**: 今週・今月に筋トレをした日数。今週は日曜始まり（カレンダーと同じ）、日本時間で数える
  4. **体重と筋トレ**: 直近30日の体重の折れ線グラフに、筋トレをした日を印で重ねる
- スマホのログアウトボタンは、ダッシュボードの一番下に残す（PC はこれまでどおりサイドバー）
- 画面の幅が 1024px 以上のときは、カードを2列に並べる（`docs/architecture.md` の「画面の骨組み」のルール）

## 入力の手軽さ

- 入力はしない。今日まだ記録していないものがあれば、1タップでそのページに移動できる
