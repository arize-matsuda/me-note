# 筋トレ記録

- 状態: 確認済み

## 目的

筋トレの内容をセットごとに記録し、種目ごとに重量や回数が伸びているかを見返せるようにする。

- 記録の入力と見返しに絞る。種目ごとの伸びのグラフは、記録がたまってから別に作る
- 体重・体脂肪率と同じく、記録はユーザーごとに分かれる

## 記録する項目

1日のトレーニングの中に複数の種目があり、1つの種目に複数のセットがある（入れ子）。

### 種目（ユーザーごとに登録する）

| 項目 | 型 | 必須 | 例 | 備考 |
|---|---|---|---|---|
| 種目名 | 文字列 | 必須 | ベンチプレス | 同じユーザーの中で同じ名前は1つだけ |

- 記録するときに一覧から選ぶ。初めての種目は、その場で追加できる

### セット

| 項目 | 型 | 必須 | 例 | 備考 |
|---|---|---|---|---|
| 日付 | 日付 | 必須 | 2026-11-18 | 最初から今日の日付（日本時間）が入っている。過去の日付は入力できる。未来の日付はできない |
| 種目 | 種目 | 必須 | ベンチプレス | 登録した種目から選ぶ |
| 重量 | 数値（kg） | 任意 | 60 | 小数点以下2桁まで（1.25kg のプレートに合わせる）。0〜500。自重の種目（懸垂など）は空にでき、空のときは「自重」と表示する |
| 回数 | 整数（回） | 必須 | 10 | 1〜999 |

- 同じ日・同じ種目の中で、セットは入力した順に並ぶ

## 画面と操作

- **置き場所**: 専用のページ `/workout`。ナビゲーション（スマホは下のバー、PC はサイドバー）に「筋トレ」（ダンベルのアイコン）を足す
- **入力**: 日付と種目を選び、セット（重量・回数）を追加していく
- **一覧**: 直近30日分（今日を含む）を、日付ごとに表示する（新しい日付が上）。その日の種目と、種目ごとのセット（例: 60kg × 10回）を並べる。それより前の記録は、あとで作るカレンダーで見られるようにする
- **グラフ・集計**: 今回は作らない
- **編集・削除**: セットの重量・回数を直す、セットを削除する。その日のその種目のセットを、まとめて削除することもできる。どちらの削除も、確認を出してから行う

## 入力の手軽さ

- 種目を選ぶと、前回その種目でやった重量・回数を最初から入れておく
- 同じ重量・回数のセットを、ボタン1つで繰り返し追加できる
- 日付には最初から今日の日付を入れておく
- 重量・回数の欄は、スマホで数字キーボードを出す

## 受け入れ条件

この条件を満たせば完成とする。

- [ ] ナビゲーション（スマホは下のバー、PC はサイドバー）の「筋トレ」から `/workout` を開ける
- [ ] `/workout` を開くと、日付に今日の日付（日本時間）が入っている
- [ ] 初めての種目を、その場で追加して選べる。2回目からは一覧から選べる
- [ ] 同じ名前の種目は2つ登録できない
- [ ] 種目を選んで重量と回数を入れて追加すると、一覧のその日のその種目にセットが表示される
- [ ] 同じ重量・回数のセットを、ボタン1つで繰り返し追加できる
- [ ] 重量を空にして追加すると、「自重」と表示される
- [ ] 2回目以降に同じ種目を選ぶと、前回その種目でやった重量・回数が入っている
- [ ] 回数が空、範囲外の値（重量 0〜500 kg・小数点以下2桁まで、回数 1〜999）、未来の日付では、エラーが表示され、保存されない
- [ ] 過去の日付を選んで記録できる
- [ ] 一覧には直近30日分が、新しい日付が上になるように、日付ごとに表示される
- [ ] セットの重量・回数を直して保存すると、一覧に反映される
- [ ] セットの削除を選ぶと確認が出て、確定すると一覧から消える。取り消すと消えない
- [ ] その日のその種目の記録をまとめて削除できる（確認が出る）
- [ ] 別のアカウントでログインすると、自分の種目と記録だけが表示される
- [ ] スマホの幅で、入力・一覧が崩れずに使え、横にはみ出さない
