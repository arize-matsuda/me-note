# 筋トレのメニュー

- 状態: 確認済み

## 目的

いつもやる種目の組み合わせを「メニュー」（例: 「胸の日」＝ベンチプレス、ダンベルフライ、ディップス）として登録しておく。記録するときにメニューを選ぶと、その日やる種目が順番に並び、種目を1つずつ選ばずにセットを足していけるようにする。

- 音楽のプレイリストのように、種目のまとまりに名前を付けて使い回す
- 毎回の種目選びの手間を減らす（[product.md](../product.md) の「入力が手軽であること」）
- 筋トレの記録そのもの（セットの保存・一覧・編集・削除）は、これまでどおり [workout.md](workout.md) のとおり

## 記録する項目

メニューの中に、種目が順番に並ぶ（入れ子）。重量・回数・セット数はメニューに持たない。

### メニュー（ユーザーごとに登録する）

| 項目 | 型 | 必須 | 例 | 備考 |
|---|---|---|---|---|
| メニュー名 | 文字列 | 必須 | 胸の日 | 同じユーザーの中で同じ名前は1つだけ |

### メニューの種目

| 項目 | 型 | 必須 | 例 | 備考 |
|---|---|---|---|---|
| 種目 | 種目 | 必須 | ベンチプレス | 登録した種目（[workout.md](workout.md)）から選ぶ。1つのメニューに同じ種目は1回だけ |
| 順番 | 整数 | 必須 | 1 | メニューの中の並び順 |

- 記録はユーザーごとに分かれる。自分のメニューだけが表示され、自分の種目だけを入れられる

## 画面と操作

### メニューの管理（`/workout/menus`）

- **置き場所**: 筋トレの中の別ページ `/workout/menus`。`/workout` に「メニューを管理」のリンクを置く。ナビゲーション（下のバー・サイドバー）の項目は増やさない
- **一覧**: 登録したメニューを並べる。各メニューに名前と、種目の名前を順番に表示する
- **作る**: メニュー名を入れ、種目を選んで順番に足していく。まだ登録していない種目は、その場で追加できる（記録の欄の「＋ 新しい種目を追加」と同じ）
- **直す**: メニュー名を変える。種目を足す・外す・並べ替える
- **削除**: メニューを削除する。確認を出してから行う。メニューを削除しても、これまでの筋トレの記録は消えない

### メニューで記録する（`/workout`）

- メニューは使わなくてもよい。記録の欄に「メニュー」の選択を置き、最初は「使わない」にする。使わないときは、これまでどおり種目を1つずつ選んで記録する
- 記録の欄でメニューを選ぶと、メニューの種目が順番に並ぶ。「使わない」に戻すと、これまでの入力に戻る
- 種目ごとに、重量・回数の入力欄と「セットを追加」のボタンを出す
  - 重量・回数には、前回その種目でやった値を最初から入れておく（これまでと同じ）
  - 同じ重量・回数のセットを、ボタン1つで繰り返し追加できる（これまでと同じ）
- 種目ごとに、その日にやったセット（例: 60kg × 10回）を並べ、進み具合がわかるようにする
- メニューを選んだだけでは何も保存されない。「セットを追加」を押したセットだけが保存される
- 保存したセットは、これまでどおり下の一覧に出て、編集・削除できる。カレンダー・ホームにもこれまでどおり反映される
- 日付はこれまでどおり選べる（最初は今日）
- ページを開き直しても、前に選んだメニューが選ばれたままになる（端末ごとに覚える）。そのメニューが削除されていたら「使わない」に戻る

## 入力の手軽さ

- メニューを1つ選べば、その日の種目がすべて並び、種目を選び直さなくてよい
- 各種目に前回の重量・回数が入っているので、そのまま「セットを追加」を押すだけで記録できる
- その日やったセットが種目ごとに見えるので、次にどの種目をやるか迷わない

## 受け入れ条件

この条件を満たせば完成とする。

- [ ] `/workout` の「メニューを管理」から `/workout/menus` を開ける
- [ ] メニュー名を入れ、種目を順番に選んで保存すると、一覧に名前と種目が順番どおりに表示される
- [ ] メニューを作るときに、まだ登録していない種目をその場で追加して入れられる
- [ ] 同じ名前のメニューは2つ登録できない。1つのメニューに同じ種目は2回入れられない
- [ ] メニュー名を変える、種目を足す・外す・並べ替えるができ、一覧に反映される
- [ ] メニューの削除を選ぶと確認が出て、確定すると一覧から消える。取り消すと消えない。これまでの筋トレの記録は残る
- [ ] `/workout` でメニューを選ぶと、メニューの種目が順番に並び、それぞれに前回の重量・回数が入っている
- [ ] 並んだ種目の「セットを追加」を押すと、その種目のセットとして保存され、その種目の欄と下の一覧に表示される
- [ ] 同じ重量・回数のセットを、ボタン1つで繰り返し追加できる
- [ ] メニューを選んだだけでは、セットは保存されない
- [ ] メニューを選んだあとにページを開き直すと、同じメニューが選ばれたままになっている
- [ ] メニューを「使わない」にすると、これまでどおり種目を1つずつ選んで記録できる
- [ ] 入力チェック（重量・回数・日付）は、これまでの記録と同じように働く
- [ ] 別のアカウントでログインすると、自分のメニューだけが表示される
- [ ] スマホの幅で、メニューの管理・メニューでの記録が崩れずに使え、横にはみ出さない

## 今回はやらないこと

- メニューの内容を一度にまとめて保存すること（やったセットを1つずつ足す）
- 曜日ごとの予定や、次にやるメニューのおすすめ
- アプリが最初から用意するメニュー
- メニューごとの集計やグラフ
- 種目の名前を変える・種目を削除する画面
- 新しいライブラリの追加
