# PWA 対応

- 状態: 実装済み

## 目的

スマホのホーム画面に me-note を追加し、アプリのように開けるようにする。

- 毎日の記録を始めるまでの手間を減らす。ブラウザを開いて URL を探す必要がなくなる（[product.md](../product.md) の「入力が手軽であること」）
- ブラウザの枠（アドレスバーなど）を出さず、画面を広く使う
- [decisions/0001](../decisions/0001-users-and-devices.md) の「スマホのホーム画面に追加して使えるよう、後から PWA に対応する」を実現する

## 記録する項目

なし（アプリの設定だけで、新しく保存するデータはない）。

## 画面と操作

### ホーム画面への追加

- iPhone: Safari の「共有」→「ホーム画面に追加」で追加できる
- Android: Chrome のメニューの「ホーム画面に追加」（または「アプリをインストール」）で追加できる
- アプリの中に「ホーム画面に追加」のボタンや案内は出さない

### ホーム画面のアイコンと名前

- アイコン: favicon と同じ人のアイコン（黒い背景に白）
- 名前: 「me-note」

### ホーム画面から開いたとき

- ブラウザの枠を出さず、全画面のアプリのように表示する
- 最初に開く画面はホーム（`/`）。ログインしていなければ、これまでどおりログイン画面になる
- 画面上部（時刻や電池の表示のあたり）は、アプリの背景と同じ色にする。本文とは重ねない
- 下のバーは、iPhone の画面下の余白と重ならない（今の作りのまま）
- 起動中の画面の背景は、アプリの背景と同じ色（薄いラベンダーがかったグレー）にする

### ログインについて

- iPhone では、ホーム画面から開いたアプリと Safari でログインの状態が分かれる。そのため、ホーム画面に追加したあと、最初の1回はアプリの中でログインが必要になる
- ログインが続く長さは、これまでどおり（最後に使った日から7日間で、使えば延びる）

## 入力の手軽さ

- ホーム画面のアイコンを1タップで開け、ログインしたままなら、すぐにホーム（ダッシュボード）が出る

## 受け入れ条件

この条件を満たせば完成とする。

- [x] iPhone の Safari で「ホーム画面に追加」すると、人のアイコンと「me-note」の名前でホーム画面に並ぶ
- [x] ホーム画面のアイコンから開くと、ブラウザの枠（アドレスバーなど）が出ずに、ホームが表示される
- [x] ホーム画面から開いたとき、画面上部の時刻などの表示と本文が重ならない
- [x] ホーム画面から開いたとき、下のバーが iPhone の画面下の余白と重ならない
- [x] ホーム画面から開いたアプリの中でログイン・ログアウトでき、記録もこれまでどおりできる
- [x] Android の Chrome でも、ホーム画面に追加して全画面で開ける（Android の端末がある場合）

## 今回はやらないこと

- オフライン（電波が弱いとき）の表示。Service Worker は入れない
- 記録し忘れなどの通知
- アプリの中の「ホーム画面に追加」のボタンや案内
- App Store・Google Play への公開
- 新しいライブラリの追加
