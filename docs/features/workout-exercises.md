# 筋トレの種目の編集

- 状態: 実装済み

## 目的

登録した筋トレの種目を、あとから直せるようにする。

- 名前を変える（例: 打ち間違い、「ベンチ」→「ベンチプレス」）
- 使わなくなった種目を削除し、選択肢をすっきりさせる
- よく使う種目を上に並べ、選ぶ手間を減らす（[product.md](../product.md) の「入力が手軽であること」）
- [workout.md](workout.md) で「今回はやらないこと」にしていた、種目の名前の変更・削除の画面を作る

## 記録する項目

新しい記録はない。種目（[workout.md](workout.md)）に次を足す。

| 項目 | 型 | 必須 | 例 | 備考 |
|---|---|---|---|---|
| 並び順 | 整数 | 必須 | 1 | 種目を選ぶところでの並び。これまでの種目は、登録した順を最初の並びにする |
| 削除したか | はい・いいえ | 必須 | いいえ | 削除しても記録を残すため、種目そのものは消さずに印を付ける |

- 種目名のルール（必須、50文字まで、同じユーザーの中で同じ名前は1つだけ）は、これまでどおり
- 記録はユーザーごとに分かれる。自分の種目だけを直せる

## 画面と操作

### 種目の管理（`/workout/exercises`）

- **置き場所**: 筋トレの中の別ページ `/workout/exercises`。`/workout` に「種目を管理」のリンクを、「メニューを管理」と並べて置く。ナビゲーション（下のバー・サイドバー）の項目は増やさない
- **一覧**: 登録した種目を、並び順どおりに表示する（削除した種目は出さない）
- **名前を変える**: 種目ごとに名前を直して保存する。これまでの記録・メニューにも新しい名前で表示される
  - 削除した種目と同じ名前には変えられない。「同じ名前の種目があります（削除済み）」と表示し、保存しない
- **並び順を変える**: 「上へ」「下へ」のボタンで並べ替える（メニューの管理と同じ）
- **削除**: 確認を出してから行う
  - 確認には、その種目が入っているメニューの名前を出し、「メニューからも外れます」と知らせる。これまでの記録は消えないことも伝える
  - 削除した種目は、記録の欄の「種目」、メニューの管理の「種目を選んで足す」、種目の管理の一覧に出なくなる
  - その種目が入っていたメニューからは外れる。種目が1つもなくなったメニューも、メニューとしては残る
  - これまでの記録（セット）は消えず、`/workout` の一覧・カレンダー・ホームにこれまでどおり種目名付きで表示され、編集・削除もできる
- 新しい種目の追加は、これまでどおり記録の欄とメニューの管理で行う

### 並び順を使う場所

- `/workout` の記録の欄の「種目」
- メニューの管理の「種目を選んで足す」
- 新しく追加した種目は、並びの一番下に入る

### 削除した種目と同じ名前を追加したとき

- 新しい種目は作らず、削除した種目を戻す。残っていた記録とつながり、前回の重量・回数も引き継ぐ
- 戻した種目は、並びの一番下に入る。削除する前に入っていたメニューには戻らない

## 入力の手軽さ

- よく使う種目を上に並べておけば、記録の欄ですぐ選べる
- 使わない種目を消せば、選択肢が短くなる
- 削除しても記録は残るので、気軽に整理できる

## 受け入れ条件

この条件を満たせば完成とする。

- [x] `/workout` の「種目を管理」から `/workout/exercises` を開ける
- [x] 種目の名前を変えて保存すると、種目の管理の一覧、記録の欄の「種目」、これまでの記録の一覧、メニューに新しい名前で表示される
- [x] 名前を空にしたり、ほかの種目（削除した種目を含む）と同じ名前にしたりすると、エラーが表示され、保存されない
- [x] 「上へ」「下へ」で並べ替えると、記録の欄の「種目」とメニューの管理の「種目を選んで足す」が同じ並びになる
- [x] 新しく追加した種目は、並びの一番下に入る
- [x] 種目の削除を選ぶと確認が出る。その種目が入っているメニューがあれば、確認にメニューの名前が出る。取り消すと消えない
- [x] 削除した種目は、記録の欄・メニューの管理の選択肢・種目の管理の一覧に出なくなり、入っていたメニューからも外れる
- [x] 削除した種目のこれまでの記録は、`/workout` の一覧・カレンダーにこれまでどおり表示され、編集・削除できる
- [x] 削除した種目と同じ名前の種目を追加すると、前の記録とつながり、前回の重量・回数が入っている
- [x] 別のアカウントでログインすると、自分の種目だけが表示され、直せる
- [x] スマホの幅で崩れずに使え、横にはみ出さない

## 今回はやらないこと

- 削除した種目の一覧や、そこから戻す画面（同じ名前で追加したときだけ戻る）
- 種目をまとめる（2つの種目の記録を1つにする）
- 種目の分類（胸・脚など）やメモ
- ドラッグでの並べ替え
- プルダウンの見た目の変更（ロードマップの10番で扱う）
- 新しいライブラリの追加
