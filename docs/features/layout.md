# 画面の骨組み（ナビゲーション）

- 状態: 確認済み

## 目的

スマホと PC のそれぞれで使いやすい画面にする。どの画面からでも、記録の画面にすぐ移動できるようにする。

- スマホでは、片手の親指で押しやすい「画面の下のバー」で移動する
- PC では、広い画面を活かし、「左のサイドバー」で移動する
- これから増える記録（筋トレなど）も、同じ骨組みに項目を足すだけで使えるようにする

## 記録する項目

なし（画面の骨組みだけで、新しく保存するデータはない）。

## 画面と操作

### スマホと PC の切り替え

- **画面の幅が 768px 以上なら PC、それより狭ければスマホ** として表示を切り替える
- ページは同じものを使い、ナビゲーションと本文の配置だけを切り替える

### ナビゲーション

| | スマホ | PC |
|---|---|---|
| 場所 | 画面の下に固定したバー | 画面の左に固定したサイドバー（幅は固定、いつも開いたまま） |
| 項目の見た目 | アイコンの下に小さな文字 | アイコンの右に文字 |
| 今いるページ | 項目の色を変えて目立たせる | 同じ |
| ログアウト | バーには入れない。トップの画面に置く | サイドバーの一番下に置く |

- 並べる項目（上から／左から）
  1. ホーム（トップ `/`）。家のアイコン
  2. 体重・体脂肪率（`/weight`）
- アイコンは、すでに入っている lucide-react を使う（ライブラリは追加しない）
- **ログイン画面（`/login`）と新規登録画面（`/signup`）には、ナビゲーションを出さない**

### 本文の配置

- スマホ：今と同じ1列。画面の上にヘッダーは出さず、ページ名は本文の見出しで表す
- PC：本文はサイドバーの右に表示する。本文の幅は最大 1024px までで、それより広い画面では左に寄せる
- `/weight`（画面の幅が 1024px 以上のとき）
  - 上の段：左に入力フォーム、右にグラフ
  - 下の段：一覧を横いっぱいに置く
  - 768〜1023px では、サイドバーの右の本文が狭く、2列にすると窮屈になるため、1列のままにする

## 入力の手軽さ

- スマホでは、どの画面からでも下のバーの1タップで記録の画面に移動できる
- 下のバーは、本文の最後の内容（一覧の最後の行など）を隠さない
- iPhone の画面下の操作バー（ホームインジケーター）と重ならないよう、その余白の分だけ下のバーを上にずらす

- [ ] PC の幅で、トップと `/weight` の画面の左にサイドバーが表示され、「ホーム」「体重・体脂肪率」に移動できる
- [ ] 今いるページの項目が、ほかの項目と見分けられる
- [ ] 各項目にアイコンと文字が表示される
- [ ] 幅 768px を境に、下のバーとサイドバーが切り替わる（両方が同時に出ない）
- [ ] PC の幅で、サイドバーの一番下のログアウトからログアウトできる
- [ ] スマホの幅で、トップの画面のログアウトからログアウトできる
- [ ] `/login` と `/signup` には、下のバーもサイドバーも表示されない
- [ ] 画面の幅が 1024px 以上の `/weight` で、入力フォームとグラフが横に並び、その下に一覧が横いっぱいに表示される（768〜1023px は1列）

- [ ] PC の広い画面（例: 1440px）で、本文が 1024px より広がらない
- [ ] スマホの幅で、横にはみ出さない
