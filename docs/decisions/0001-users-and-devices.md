# 0001: 利用者と利用端末

- 日付: 2026-11-17
- 状態: 採用

## 背景

me-note は、体重・筋トレ・家計簿など生活の記録を1つにまとめて管理するアプリ。
誰が、どの端末で使うかによって、ログインやデータ設計、画面の作り方が変わる。

## 決定

- 最初は自分だけが使う。いずれは公開して、ほかの人も自分のアカウントで使えるようにする
- そのため、すべての記録に「誰の記録か」（ユーザーID）を持たせる
- 最初は新規登録を閉じておき、公開するときに開放する
- スマホと PC の両方で使う。1つの Web アプリを、スマホを基準にした画面で作り、PC では広く表示する
- スマホのホーム画面に追加して使えるよう、後から PWA に対応する

## 理由

- ユーザーID は後から追加すると既存データとテーブルをすべて直す必要があるが、最初から入れておけば手間はほとんどかからない
- 記録するのは主にスマホなので、スマホで入力しやすいことを優先する

## 今はやらないこと

- パスワード再発行、利用規約、管理画面など、他人に使ってもらうための機能（公開するときに作る）
