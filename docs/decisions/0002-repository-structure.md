# 0002: リポジトリ構成と役割分担

- 日付: 2026-11-17
- 状態: 採用

## 背景

画面は Next.js で作り、AI・分析の部分は Python で作りたい。

## 決定

- リポジトリのルート直下に `web/` と `ai/` を置く（`apps/` にはまとめない）
  - `web/` — Next.js（TypeScript）。画面と記録の作成・編集・削除を担当する
  - `ai/` — Python。分析・要約などを担当する。**実装は後で行う**
- DB のスキーマとマイグレーションは `web/` だけが管理する。`ai/` は DB を読み取るだけにする
- ブラウザから `ai/` を直接呼ばず、必ず Next.js のサーバー側を経由する

## 理由

- アプリは2つだけで言語も違い、共有するパッケージも作らないため、`apps/` で1階層深くする必要がない。アプリが3つ以上になったら見直す
- 2つのアプリから DB のスキーマを変更すると不整合が起きやすいため、管理する側を1つに絞る
- `ai/` を外部に公開しないことで、ログインや API キーの管理を `web/` にまとめられる
