# 0005: 開発の進め方

- 日付: 2026-11-17
- 状態: 採用

## 背景

AI を中心にした開発（AI 駆動開発）で進めたい。
ただし、一度に多くのものを入れると内容を把握できなくなるため、土台づくりは慎重に進めたい。

## 決定

- **土台ができるまでは、1つずつゆっくり進める**
  - 1回に1つのことだけを行い、確認してから次に進む
  - 品質チェック（lint、型チェック、テスト、CI）は必要になったときに1つずつ入れる
- **土台ができたら、AI が実装し、人は承認と修正だけを行う**
  - 人は仕様を一緒に決め、AI が作った PR を確認して承認・修正する

## 土台づくりの手順

具体的な手順と進み具合は [product.md のロードマップ](../product.md#ロードマップ) で管理する。

各ステップで必要なこと（ライブラリの選択など）は、そのステップに入る直前に決める。

## 理由

- 承認だけで進めるには、AI が方針を理解でき（ドキュメント）、作業結果を確認しやすく（PR）、コードを全部読まなくても壊れていないとわかる（チェック）必要がある
- 土台を自分で理解しておかないと、後から AI の作業を正しく判断できない
