# 0008: CI で lint と型チェックを自動実行する

- 日付: 2026-11-17
- 状態: 採用

## 背景

人は AI が作った PR を承認するだけで進めたい（[0005](0005-development-process.md)）。
そのためには、コードを全部読まなくても、少なくとも書き方と型に誤りがないことが自動でわかる必要がある。

## 決定

- **GitHub Actions で CI を実行する**（`.github/workflows/ci.yml`）
- **チェックする内容は lint と型チェック**
  - lint: `pnpm lint`（Biome）
  - 型チェック: `pnpm typecheck`（`next typegen && tsc --noEmit`）
  - ビルドは今は入れない。環境変数が必要になるステップ5以降で検討する
- **実行するタイミング**: PR を作ったとき・更新したとき、main にマージされたとき
- **CI が通らないと PR をマージできない**（ルールセット「main を保護」の必須チェックにする）
- **Node.js のバージョンは 26**。ルートの `.nvmrc` に書き、手元と CI で同じバージョンを使う

## 理由

- AI の PR にエラーがあれば、マージボタンを押せなくなる。人が見落としても main が壊れない
- Next.js の型定義ファイル（`next-env.d.ts`）は git の管理対象外のため、`next typegen` を先に実行して、CI と手元で同じ条件にする
- 型チェックをコマンド（`pnpm typecheck`）にまとめることで、CLAUDE.md・skill・CI で同じコマンドを使える
- Node.js 26 は 2026年10月から長期サポート版（LTS）で、手元の環境とも同じ
