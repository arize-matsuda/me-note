# 0003: 公開先・データベース・ログイン

- 日付: 2026-11-17
- 状態: 採用

## 背景

スマホから外出先でも使い、将来はほかの人にも使ってもらうため、インターネットに公開する必要がある。
公開する以上、自分のデータを他人に見られないようにログインも必要になる。
個人で使っているうちは、無料またはほぼ無料で運用したい。

## 検討した案

| 案 | 構成 | 特徴 |
|---|---|---|
| A | Vercel ＋ Neon ＋ Better Auth | ユーザー情報も含めて、すべてのデータが自分の PostgreSQL に入る。特定のサービスに縛られにくい |
| B | Vercel ＋ Supabase（DB とログイン） | 1つのサービスで済み手軽。その代わり Supabase への依存度が高い |

## 決定

A 案を採用する。

- 公開先: **Vercel**
- データベース: **Neon**（PostgreSQL）
- ログイン: **Better Auth**（ユーザー情報は自分の DB に保存する）

## 理由

- 「データを自分の手元に置く」という目的に合う
- 後から乗り換えやすい
- 後で Python（`ai/`）から DB を読むときも、普通の PostgreSQL なので構成がシンプル
- Vercel は Next.js の開発元で、最新機能への対応が最も確実

## 注意

- Vercel の無料プランは非商用に限られる。公開して収益化する場合は見直す
- 料金や無料枠の条件は変わることがあるため、契約前に公式サイトで確認する
